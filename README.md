# Casa Tupka — Frontend Redesign

A responsive editorial landing site exploring Casa Tupka through the lens of premium Indian nightlife and Mexican agave heritage.

## Local preview

This initial version is a static site. Open `index.html` directly, or serve the repository with a local static server.

## Design direction

- Deep agave green, aged brass, bone and warm amber
- Editorial serif typography with restrained sans-serif labels
- Responsive navigation and sections
- Reduced-motion support and accessible interaction states

## Important

This is a frontend concept. Replace placeholder art direction and verify all product, provenance, age-gate, legal and commerce details with the brand before launch. It has not been deployed to the live website.
